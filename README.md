# Personal Finance Tracker

A premium, full-stack personal financial application designed to effortlessly log ledger entries, visualize categories, and capture deep spending trends. Built with a responsive layout featuring a hardware-accelerated interactive frontend and a secure, time-synchronized decentralized multi-factor authentication backend.

---

##  Key Features

###  Premium User Experience & UI
* **Interactive Background Matrix:** High-performance background lighting grid that dynamically anchors and follows the user's cursor paths using hardware-accelerated CSS properties.
* **Modern Product Showcase:** Replaced standard technical jargon with clean, client-facing micro-copy tailored for starting and scaling individual financial workflows.
* **Unified Workspace:** Full CRUD capabilities for adding, updating, and removing ledger items with instantaneous balance updates.

###  Visual Analytics & Currency Engine
* **Insights Panel:** Dynamic breakdown distributions, category charts, and summarized analytical status trackers.
* **Timeline Constraints:** Granular statement filters allowing users to audit expenditures between customized dates.
* **Global Currency Exchanger:** One-click dynamic localization mapping that shifts the full ledger framework smoothly between multiple currency symbols (`₹`, `$`, `€`, `£`) using the native browser `Intl.NumberFormat` API.
* **Real-Time Estimation Tool:** A reactive currency conversion widget embedded directly into the workspace layout to run on-the-fly cross-currency ratio estimations as you type.

###  Advanced Multi-Factor Security
* **Decentralized TOTP Verification:** Two-Factor Identity protection leveraging Time-Based One-Time Passwords (`pyotp`) synced to the user's secure smartphone device (Google or Microsoft Authenticator).
* **On-Demand QR Enrollment:** Automated secure QR configurations injected seamlessly into the user signup flow using modern inline cryptographic string renders.
* **Offline Security Matrix:** Multi-factor checks running entirely without external transactional email reliance, locking accounts safely from remote takeover.
